# Práctica 3 – Juego de matemáticas JMS

## Descripción

**Juego de matemáticas JMS** es un proyecto desarrollado para la Práctica 3 de la asignatura de Desarrollo Web en Entorno Cliente (DWEC), correspondiente al segundo curso del ciclo formativo de Desarrollo de Aplicaciones Web (DAW).

El proyecto consiste en un sencillo juego matemático en el que el usuario crea su perfil y resuelve operaciones para conseguir puntos.

## Funcionamiento

- Creación y validación del perfil del jugador.
- Cálculo de la edad a partir de la fecha de nacimiento.
- Personalización del mensaje de bienvenida.
- Generación aleatoria de operaciones matemáticas.
- Comprobación de respuestas y sistema de puntuación.
- Pistas para ayudar al jugador.
- Ventana adicional con información y ayuda.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## Conceptos de JavaScript aplicados

Durante el desarrollo se trabajan los siguientes contenidos:

- Objetos `String` y `Date`.
- Funciones `Math` y manejo de números.
- Arrays.
- Manipulación del DOM.
- Eventos.
- Modificación dinámica de estilos.
- Ventanas adicionales del navegador.
- Cookies.
- `sessionStorage` y `localStorage`.

## Ejecución

Para utilizar el juego:

1. Descargar o clonar el repositorio.
2. Acceder a la carpeta `TEMA 3/juego`.
3. Abrir el archivo `index.html` en un navegador web.
4. Crear un perfil para comenzar a jugar.
